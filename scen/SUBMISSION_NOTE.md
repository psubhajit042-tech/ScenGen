## ScenGen Submission Folder

This `scen` folder contains the main project files for submission:

- Python source files
- Required JSON configuration files
- Run/setup scripts
- Core project documentation

Intentionally excluded:

- Generated screenshots and outputs
- `__pycache__` files
- virtual environment files
- large OCR model folders
- temporary or log files

Suggested starting files:

- `test.py`
- `testbot/conf.json`
- `README.md`
- `requirements.txt`
